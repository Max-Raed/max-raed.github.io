Gaze-Adaptive Interfaces: Understanding User Attention in Dynamic Environments

Max Raed, Jane Doe, John Smith

PDF Code Talk Video ACM DL
Teaser Image · 1200 × 675 px

An overview of our gaze-adaptive system: real-time attention estimation drives dynamic layout adjustments, reducing visual search time in cluttered interfaces.

Abstract

Modern user interfaces present an ever-growing density of information. Users must continually navigate complex visual hierarchies, often under time pressure. We present GazeFlow, a system that continuously estimates user attention from commodity eye-tracking hardware and adapts the interface layout in real time to surface relevant content and suppress distractors.

In a within-subject study with 24 participants (N = 24), GazeFlow reduced task completion time by 23% and perceived cognitive load by 18% compared to a static baseline. We discuss implications for designing attention-aware interfaces and the privacy considerations of always-on gaze data.

Introduction

As digital workspaces grow denser, the cost of visual navigation has become a meaningful contributor to user fatigue and error rates. Prior work in adaptive interfaces has largely relied on explicit user input or coarse contextual signals; gaze, a direct proxy for visual attention, remains underexplored as a continuous adaptation signal in everyday desktop environments.

We address this gap by building and evaluating a real-time gaze-adaptive interface that operates within a standard office workflow without requiring explicit user effort.

Contributions

  • A real-time gaze processing pipeline suitable for commodity eye-trackers (≤ 60 Hz)
  • GazeFlow: an adaptive layout engine that reweights UI element salience based on attention estimates
  • A controlled user study (N = 24) demonstrating significant reductions in task time and cognitive load
  • Design guidelines for attention-aware interfaces, including privacy-preserving gaze handling
Figure — System Architecture

Figure 1: GazeFlow system architecture. Raw gaze coordinates are processed by an attention estimation module; the layout engine receives attention maps and reflows UI elements every 500 ms.

Results

Participants completed information-retrieval tasks significantly faster with GazeFlow active (M = 18.4 s, SD = 4.1) compared to the static baseline (M = 23.9 s, SD = 5.3; t(23) = 4.82, p < .001, d = 0.98). NASA-TLX scores indicated lower perceived mental demand (GazeFlow: M = 42.1 vs. Baseline: M = 51.3).

Qualitative feedback highlighted two tension points: some participants found frequent layout changes disorienting during exploratory tasks, suggesting an adaptivity threshold mechanism as future work.
